# Path

A list of three rows and a picture screen.

## What it does

The list has three rows with a globe and the text Hello, world. A row opens a second screen. A tap on the globe enlarges it. A red Spicy label sits at the bottom.

## Stack

SwiftUI.

## Run

```bash
git clone https://github.com/dpogonia/Path.git
cd Path
open Path.xcodeproj
```

Run the **Path** scheme on an iPhone simulator.

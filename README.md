# Path

Список из трёх строк и экран с картинкой.

## Что умеет приложение

В списке три строки с глобусом и текстом Hello, world. Строка открывает второй экран. Касание глобуса увеличивает его. Внизу красная плашка Spicy.

## Стек

SwiftUI.

## Запуск

```bash
git clone https://github.com/dpogonia/Path.git
cd Path
open Path.xcodeproj
```

Запустите схему **Path** на симуляторе iPhone.
